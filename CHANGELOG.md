# Changelog

## 0.5.37

- Expanded the right-click settings menu with Appearance, Behaviour, and Desktop Behaviour sections.
- Added Dark, Light, and Match system themes.
- Added adjustable background opacity and card corner radius.
- Added a toggle for hover-to-expand.
- Added expand/collapse speed choices: Instant, Fast, Normal, and Slow.
- Added temporary popup auto-hide choices: 2, 4, 8 seconds, or Never.
- Added an option to disable automatic hiding when foreground windows cover the card.
- All preferences persist across restarts and updates; Reset to defaults restores the original Vinyl/Dark behaviour.

## 0.5.36

- Added a right-click settings menu to the visible player.
- Added three persistent artwork modes: Vinyl (default), Album, and Nothing.
- Preserved interactive vinyl scrubbing only in Vinyl mode; Album mode uses a static cover image.
- Nothing mode hides the artwork and gives track/player text the freed space.
- Added Reset to defaults (Vinyl).
- Renamed visible product identity to MediaTable while retaining executable and helper identifiers for in-place upgrades.
